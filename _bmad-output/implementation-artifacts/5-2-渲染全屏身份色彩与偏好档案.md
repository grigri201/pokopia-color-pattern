# Story 5.2: 渲染全屏身份、色彩与偏好档案

Status: done

## Story

As a 用户,
I want 全屏模式按照 Open Design 展示当前 Pokemon 的身份、色彩和偏好档案,
so that 我可以清楚理解这只 Pokemon 的视觉主色、色板构成和喜好/偏好词。

## Acceptance Criteria

1. Given 全屏 overlay 已打开且 selected Pokemon 数据已加载, when 身份区渲染, then 页面展示 Pokemon 名称、编号和 slug, and 右侧 Pokemon 画像卡片展示 runtime Pokemon 图像、可读 alt，以及大型编号 figcaption。
2. Given selected Pokemon 有主色, when 色彩数值区渲染, then 页面展示 HEX、RGB 和 CMYK 三组数值, and RGB/CMYK 从同一主色 deterministic 派生，不写入第二套颜色来源。
3. Given selected Pokemon 有 palette 数据, when 色板模块渲染, then 页面按 Open Design 展示色板 swatch、序号、HEX 和 percent, and 色板下方渲染中文标题 `图案` 的色彩图案模块。
4. Given selected Pokemon 有 `preferenceTerms`, when `偏好档案` 模块渲染, then 所有偏好词以纵向条目展示, and 偏好档案作为独立模块存在，不只出现在推荐卡片中。
5. Given selected Pokemon 的 `preferenceTerms` 为空，例如 Ditto, when `偏好档案` 模块渲染, then 模块仍可见, and 显示可读空状态而不是隐藏模块或留下空白卡片。
6. Given 全屏 overlay 渲染任何用户可见文本, when 文本来自 Pokemon metadata、slug、palette 或 preference terms, then 使用 DOM text API 或 HTML escape, and 不把 manifest 字段直接拼入未转义 HTML。

## Tasks / Subtasks

- [x] 渲染身份区和画像卡片 (AC: 1)
  - [x] 左侧身份区显示编号、slug、Pokemon display name。
  - [x] 右侧 `fullscreen-pokemon-card` 使用当前 runtime Pokemon 图像和大型编号 figcaption。
  - [x] 图片 alt 包含当前 Pokemon 名称。
- [x] 渲染主色数值 (AC: 2)
  - [x] 显示 HEX。
  - [x] 从 HEX deterministic 派生 RGB。
  - [x] 从 RGB deterministic 派生 CMYK，格式与 Open Design 保持一致。
- [x] 渲染色板和图案 (AC: 3)
  - [x] 色板条目包含序号、HEX 和 percent。
  - [x] 图案模块使用 palette 生成稳定网格，不引入随机布局。
- [x] 渲染偏好档案 (AC: 4, 5)
  - [x] 偏好词作为独立 `偏好档案` 模块展示。
  - [x] 偏好词为空时显示可读空状态。
  - [x] 偏好词文案遵守当前 locale 的展示策略；内部匹配值不被改写。
- [x] 保持安全渲染 (AC: 6)
  - [x] 所有 manifest/generated data 文本使用 DOM text API 或 escape。

## Dev Notes

- Story 5.1 应先提供 overlay shell、entry/exit 和 toolbar。本故事只补齐 overlay 主体内容。
- `PokemonIndexEntry` 已包含 `sequence`、`slug`、`name`、`zhName`、`imagePath`、`primaryColor`、`palette`、`pattern` 和 `preferenceTerms`。
- 当前 Open Design HTML 样本使用 `No.180 利欧路`；实际实现必须从 selected Pokemon 数据渲染，不要写死 Riolu。
- `偏好档案` 是页面级信息，不是推荐卡片里的 `matchedPreferenceTerms` 替代品。
- 本故事不实现壁纸导出按钮、下载或预览。
