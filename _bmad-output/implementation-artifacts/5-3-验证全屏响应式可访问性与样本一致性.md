# Story 5.3: 验证全屏响应式、可访问性与 Open Design 样本一致性

Status: ready-for-dev

## Story

As a 维护者,
I want 全屏 overlay 有响应式、可访问性和样本验证,
so that Open Design 全屏体验不会在桌面、窄屏、移动端或后续构建中退化。

## Acceptance Criteria

1. Given 视口宽度大于 Open Design 桌面阈值, when 全屏 overlay 渲染, then 主体为左侧信息区、右侧 Pokemon 画像卡片的左右结构, and 左侧信息区包含上方身份区、下方主色/色板/图案区和偏好档案区。
2. Given 视口进入中窄屏或移动端, when 全屏 overlay 渲染, then 布局改为纵向滚动, and 信息区在上、Pokemon 画像卡片在下，信息区内部依次显示身份、主色/色板、偏好。
3. Given Open Design 指定样本 `No.180 利欧路`, when 全屏 overlay 渲染, then 中文界面、色板、偏好词换行和画像卡牌布局符合 Open Design 标记和视觉结构。
4. Given Open Design 指定样本 `Ditto`, when 全屏 overlay 渲染, then `偏好档案` 显示空状态, and 空状态不造成布局塌陷。
5. Given Open Design 指定样本 `Pikachu`, when 全屏 overlay 在移动视口渲染, then Pokemon 图像与标题尺度不重叠、不横向溢出, and 关闭按钮与语言切换按钮仍可点击和键盘访问。
6. Given production build 或 release verification 运行, when 全屏相关校验执行, then 验证全屏入口、打开、关闭、Escape、焦点返回、URL 不变和 `/assets/runtime/**` 图片路径, and 不引用 `/docs/pokopia_image_sources/**`。
7. Given 用户寻找壁纸导出能力, when 本轮 Epic 5 交付完成, then 页面不暴露未实现的导出按钮或假下载能力, and 文档保留“壁纸导出后续单独确认”的范围说明。

## Tasks / Subtasks

- [ ] 添加响应式验证 (AC: 1, 2, 5)
  - [ ] 覆盖桌面左右结构。
  - [ ] 覆盖中窄屏和移动端纵向滚动结构。
  - [ ] 检查标题、画像、偏好词和工具栏不重叠、不横向溢出。
- [ ] 添加 Open Design 样本验证 (AC: 3, 4, 5)
  - [ ] 覆盖 `No.180 利欧路`。
  - [ ] 覆盖 `Ditto` 偏好词空状态。
  - [ ] 覆盖 `Pikachu` 移动端图像与标题尺度。
- [ ] 添加交互与可访问性验证 (AC: 6)
  - [ ] 覆盖全屏入口、关闭按钮、Escape。
  - [ ] 覆盖打开后的焦点移动和关闭后的焦点返回。
  - [ ] 覆盖 URL/hash/history 不因全屏状态变化。
- [ ] 添加 runtime boundary 验证 (AC: 6)
  - [ ] 验证全屏 Pokemon image 使用 `/assets/runtime/**`。
  - [ ] 验证全屏相关 HTML/JS/CSS 不引用 `/docs/pokopia_image_sources/**`。
- [ ] 锁定壁纸导出范围 (AC: 7)
  - [ ] 确认本轮没有可点击的下载/导出/生成壁纸假入口。
  - [ ] 在文档或 story completion notes 中保留后续壁纸模板需单独确认的说明。

## Dev Notes

- 本故事是 Epic 5 的 release-quality gate，不应新增未在 Open Design 中定义的新视觉模式。
- Open Design 断点参考：`1180px` 以上左右结构，`1180px` 以下纵向结构，`820px` 以下单列信息区。
- 如果 Playwright 可用，优先用 browser smoke 验证交互和视口；如果 build 环境不支持浏览器，至少保留可运行的 DOM/unit 验证，并说明 smoke 运行方式。
- 不要把壁纸导出当作本轮缺口补做。设计规格明确本轮不实现导出。

### Project Structure Notes

- 预期涉及：`tests/smoke/**` 或现有 smoke 测试、`src/styles.css`、`package.json` 验证脚本（如需要）。
- 不要让 `npm run build` 依赖不可用的浏览器安装；浏览器 smoke 可继续由 release verification 命令承载。
